# Code of conduct

Critique code and evidence, not people. Harassment, threats, discrimination, doxxing, impersonation, spam, and unauthorized-access attempts are not permitted. Keep reports relevant and reproducible; never expose private information.

Maintainers may remove content, restrict participation, or revoke access to protect the project. Enforcement/access changes require owner review; a maintainer must not decide a complaint about themselves alone. GitHub's platform reporting tools remain available for owner-related abuse.
