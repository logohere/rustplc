# Port plan

Preserve observable behavior from UPSTREAM_BASELINE.md. Baseline updates are separate reviewed issues with new differential evidence. Private lab integrations and site-specific projects are excluded.

1. Link an existing issue or file a reproducible report with source pins and runnable acceptance checks.
2. Reproduce before editing; change the smallest shared cause.
3. Run a focused regression and applicable compiler/runtime/protocol/rendered-editor checks.
4. Review compatibility, recovery, dependencies, privacy, and licenses together.
5. Merge through CONTRIBUTING.md; publish only after owner review.

No compatibility claim without evidence, silent unsupported fallback, or field/safety claim from simulation. A clean checkout must not require a private repository or maintainer machine profile. Source and packaged artifacts receive separate privacy/provenance audits.

The parity ledger records historical evidence. Track new work in [repository issues](https://github.com/logohere/rustplc/issues); private-repository issue numbers are not imported.
